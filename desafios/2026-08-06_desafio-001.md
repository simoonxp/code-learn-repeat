## 🎯 Enunciado

Escreva uma função em Python chamada `contar_vogais` que receba uma string e retorne o número de vogais (a, e, i, o, u) presentes nela, ignorando maiúsculas e minúsculas.

**Exemplo:**
```python
contar_vogais("Felipe Simon")  # retorna 5
contar_vogais("Python")        # retorna 1
contar_vogais("AEIOU")         # retorna 5
```

---

## ✅ Solução do @simoonxp

```python
vogais = ['a', 'e', 'i', 'o', 'u']
frase = str(input('Qual sua frase? '))
contador = 0

for letra in frase.lower():
    if letra in vogais:
        contador += 1

print(contador)
```

**O que o autor pensou corretamente ✔️**
- Usar uma lista de vogais
- Usar uma variável `contador` iniciada em 0
- Ideia de percorrer a frase comparando com as vogais

**Erros de sintaxe corrigidos 🔧**
- `INPUT` → `input` (Python é case-sensitive)
- Parêntese faltando no `input`
- Faltou o `for letra in frase.lower():`
- Faltou o `if letra in vogais:`
- `=+1` → `+= 1` (operador correto de incremento)
- Faltou o `print(contador)` no final

---

## 💡 Aprendizado do dia

> `+=` adiciona ao valor atual. `=+` apenas atribui um número positivo.
> `contador += 1` é o mesmo que `contador = contador + 1`.
