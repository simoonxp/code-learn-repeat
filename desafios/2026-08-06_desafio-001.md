## 🎯 Enunciado

Escreva uma função em Python chamada `contar_vogais` que receba uma string e retorne o número de vogais (a, e, i, o, u) presentes nela, ignorando maiúsculas e minúsculas.

**Exemplo:**
```python
contar_vogais("Felipe Simon")  # retorna 5
contar_vogais("Python")        # retorna 1
contar_vogais("AEIOU")         # retorna 5
```

---

## ✅ Solução do @simoonxp

```python
def contar_vogais(texto):
    vogais = ['a', 'e', 'i', 'o', 'u']
    return sum(1 for letra in texto.lower() if letra in vogais)
```

**Raciocínio:** Criar uma lista com as vogais, converter o texto para minúsculas e contar cada letra que estiver na lista. ✔️

---

## 💡 Dica que foi usada

Converter para `.lower()` antes de verificar garante que maiúsculas e minúsculas sejam tratadas igualmente.
