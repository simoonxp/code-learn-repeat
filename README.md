## 📅 Desafio de Hoje — #003

### 🎯 Enunciado

Escreva uma função chamada `inverter_palavras` que receba uma frase e retorne a frase com as palavras em ordem invertida.

**Exemplo:**
```python
inverter_palavras("Felipe gosta de Python")  # retorna "Python de gosta Felipe"
inverter_palavras("Olá mundo")               # retorna "mundo Olá"
```
